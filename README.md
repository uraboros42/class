# Домашнее задание: Классы (C#)

Реализованы классы `Unit` и `Weapon` согласно ТЗ.

Файлы:
- `Unit.cs` — реализация класса `Unit`.
- `Weapon.cs` — реализация класса `Weapon`.
- `Program.cs` — демонстрация работы классов.
- `RPG.csproj` — проект .NET Console.

Как запустить:

```bash
dotnet run --project RPG.csproj
```

Примечание: проект таргетирует `net8.0`. При необходимости измените `TargetFramework` в `RPG.csproj`.
